# Vigil

Local-first Gmail triage assistant. Reads your inbox, sorts emails into
Urgent / Needs Reply / FYI using a locally-run AI model (Ollama), flags
invoices, and supports standing "watches" and local file search. Nothing
about your email leaves your machine.

Grab the latest build from the **Releases** page on the right side of
this repo. See [CHANGELOG.md](CHANGELOG.md) for what's changed in each
version.
